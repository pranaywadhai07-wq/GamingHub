GAMING HUB
==========

Created with:

HTML
CSS
JavaScript


HOW TO RUN
==========

1. Open the Gaming-Hub folder in VS Code.

2. Make sure these files are present:

   index.html
   style.css
   script.js

3. Open index.html in your browser.

OR

4. Install the Live Server extension in VS Code.

5. Right-click index.html.

6. Select:

   Open with Live Server


IMPORTANT
=========

This project does NOT require:

Node.js
Express
API
Server
AI API
Internet connection


FEATURES
========

- Gaming dashboard
- Sensitivity calculator
- DPI/eDPI calculator

- Gaming statistics
